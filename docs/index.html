How each day works

  1. Mission briefingWhat you will be able to do tonight, and what to have ready.
  2. ConceptsOne idea per card, with a diagram you can click.
  3. Try-it terminalA simulation that replays the manual's real output.
  4. Real labThe validated commands, byte for byte, as a checklist.
  5. Quick checksMultiple choice, predict the output, order the steps, build the command.
  6. Boss challengeA scenario that combines the day's skills.
  7. RecapFlashcards, your badge and a look at tomorrow.

Progress is saved in this browser only. The reference workstation runs kernel 7.2.7-200.fc44, QEMU 10.2.2, libvirt 12.0.0 with modular daemons, virt-install 5.1.0 and Fedora Cloud image build 44-1.7. The osinfo database has no fedora44 entry yet, so the course uses --osinfo fedora43, the nearest one.
