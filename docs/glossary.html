Day 10

EPT misconfiguration

The exit caused by accessing a GPA without a memory slot, where KVM wrote a deliberately invalid entry; it is handled as MMIO. see 13.1

Day 10

EPT violation

The exit caused by the first access to a guest page without an EPT entry. If a memory slot covers it, KVM writes the entry and resumes the guest; if not, KVM writes a deliberately invalid entry and treats the access as MMIO (13.2's store to 0x5000). see 13.1, 13.2

Day 8

Exit (from KVM_RUN)

Each return of the KVM_RUN ioctl to the VMM; run->exit_reason says why the guest stopped. Not every VM exit of the CPU becomes one: KVM handles most itself (Day 10). see 11.4, 13.1
